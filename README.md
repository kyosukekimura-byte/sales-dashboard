# 売上ダッシュボード

CSVの売上データから、合計売上・月別推移・商品別ランキング・平均単価・売れ筋分析を確認できるローカルダッシュボードです。

## 使い方

```bash
python server.py
```

起動後、ブラウザで以下を開きます。

```
http://localhost:8000/売上ダッシュボード.html
```

## 機能

- 期間・カテゴリでの絞り込み
- 月別売上推移、商品別売上ランキング
- 商品別の平均単価、販売数量ベースの売れ筋分析
- フォルダ内のCSVファイルをドロップダウンで切り替え
- CSVファイルのドラッグ&ドロップ読み込み(ブラウザに自動保存され、次回も選択可能)

## ファイル構成

- `売上ダッシュボード.html` — ダッシュボード本体
- `server.py` — ローカルサーバー(CSV一覧・配信用)
- `売上データ.csv` / `売上データ_4-6月.csv` — サンプルデータ

## CSVフォーマット

```
日付,商品名,カテゴリ,地域,数量,単価,売上金額
```
